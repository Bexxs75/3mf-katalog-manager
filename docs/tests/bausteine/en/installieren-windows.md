STEP preview is included in this installer.

On the first start Windows will probably show "Windows protected your PC". Click **More info** and then **Run anyway**. Install with the default settings.

The app installs as "{{produkt}}", independent of a normal installation.

The release page also lists a second installer ending in `-Setup.exe` (installs without administrator rights). The steps here use the `.msi`; use the `-Setup.exe` only if the test plan asks for it, and do not install both side by side.
