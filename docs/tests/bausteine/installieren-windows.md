Die STEP-Vorschau ist in diesem Installer enthalten.

Windows zeigt beim ersten Start wahrscheinlich „Der Computer wurde durch Windows geschützt“. Klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**. Installiere mit den Standardeinstellungen.

Die App installiert sich als „{{produkt}}“, unabhängig von einer normalen Installation.

Auf der Release-Seite steht außerdem ein zweiter Installer mit der Endung `-Setup.exe` (installiert ohne Administratorrechte). Die Schritte hier verwenden die `.msi`; nimm die `-Setup.exe` nur, wenn der Testplan es verlangt, und installiere nicht beide nebeneinander.
