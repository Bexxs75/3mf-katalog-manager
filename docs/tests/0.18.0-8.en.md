# 1 · New in 0.18.0-8 (RC3): Drag cards out

## N18080 · Switch and cards without handles
Steps:
1. Open Settings → Slicers & services → Passing files on. Enable “Drag files out of the catalog” and read the help text.
2. Inspect an individual STL, OBJ or 3MF card in both Compact and Comfort grid density and in the list. Then open the model's detail page.
3. Return to the catalog and drag the card onto a test folder inside the window. Undo the move.
Expected: Cards and list rows have no drag handles; the heart, license badge and selection box remain reachable. The detail page retains its drag-out handle. Inside the window, the file moves into the folder with a message and undo. The help text describes dragging the card out and the keyboard alternatives.
Note: Use the desktop app with imported test models and a test folder. Bundle cards and collection reordering do not support dragging out; cards cannot be dragged during an import.

## N18081 · Drag a card into a file manager or onto the desktop
Steps:
1. Keep the switch from N18080 enabled. Open an empty test folder in the file manager beside the catalog window.
2. Drag a card across the window edge into the test folder, keeping the button pressed until reaching the target, then release it. Repeat from the list and onto the desktop.
3. Select several individual models and drag one selected card into the test folder.
4. Check the files handed over and the originals in the catalog. Repeat with a file name containing spaces and umlauts.
Expected: The files arrive at the destination; catalog files stay intact. For multiple selection, the selected 3MF, STL and OBJ files are handed over. Further drags work without restarting.
Note: Empty the destination folder if necessary so existing names do not obscure the result. At most 64 eligible files per drag.

## N18082 · Drag a card into a slicer
Steps:
1. Open an installed slicer beside the catalog window and enable dragging out.
2. Drag an STL or 3MF card straight from the catalog into the slicer's workspace. Keep the button pressed until reaching the target.
3. Confirm the slicer's opening dialog if shown and repeat the drag.
Expected: The slicer offers to open the file or displays the model. The catalog file stays intact and the app remains responsive.
Note: Skip without an installed slicer and name the target program in the result. On Windows, start the slicer without administrator rights.

## N18083 · Hint with the switch off
Steps:
1. Restart the app and turn off “Drag files out of the catalog”.
2. Drag a card across the window edge. Release and repeat the attempt.
3. On the first attempt, follow the hint into the settings. Enable dragging out there and drag into the file manager again.
Expected: With the switch off, no native drag starts. A hint points to the setting and appears only once per app session. Dragging out works after enabling the switch. Moving inside the window also works with the switch off.

## N18084 · Linux: slicers, text editor and file names
Only: linux
Steps:
1. Enable dragging out. Prepare test models with spaces and umlauts in their names, for example “Würfel groß.stl”.
2. Drag a card into Bambu Studio and OrcaSlicer; confirm any opening dialog. Repeat each drag.
3. If available, drag a small text-based OBJ or ASCII STL file into gedit.
Expected: The slicers open the model or show the opening dialog; gedit shows the file contents. Spaces and umlauts do not prevent the handover. The app stays responsive after repeated drags.
Note: Skip missing target programs and name them in the result. Test under X11; Wayland is not required. Do not use artificial targets that report completion before the button is released.

## N18085 · Release during preparation
Steps:
1. Enable dragging out and drag a large test file across the window edge. Release the button immediately after crossing, while the temporary copy might still be prepared.
2. Repeat several times. Then move the pointer and click an empty area. Finally perform a normal drag all the way into a test folder in the file manager.
Expected: If the button has already been released before native dragging starts, the drag is cancelled without an error toast. No drag remains stuck until the next click, and that click does not drop a file. The next normal drag works.
Note: Timing depends on file size and computer; report if not reproducible. On macOS, also try dragging a card immediately after switching focus from the file manager.

# 2 · New in 0.18.0-8 (RC3): Settings: focus when saving

## N18086 · Keyboard focus stays on the switch
Steps:
1. Open settings. Use Tab to reach “Drag files out of the catalog” under Slicers & services.
2. Toggle the switch with Space and wait for the value to be saved. Then press Tab and Shift+Tab.
3. Repeat with another switch that saves a setting, for example under General. Check both a wide window and a narrow window with overlaid settings.
Expected: After saving, focus stays on the activated switch instead of jumping to the heading or start. Tab continues navigation from there; Shift+Tab returns. The setting is retained after closing and reopening settings.

# 3 · New in 0.18.0-8 (RC3): Detail panel width

## N18087 · Change width with the mouse
Steps:
1. Select a model in the catalog so the detail panel is visible on the right. Use a sufficiently wide window.
2. Drag the divider at the left edge of the detail panel left and right, including to the limits.
3. Close and reopen the detail panel, then restart the app.
Expected: The panel becomes wider or narrower; the limits preserve space for the catalog. The chosen width is restored. In a small window the panel remains usable and its contents can be scrolled.

## N18088 · Keyboard width and reset
Steps:
1. Focus the divider at the left edge of the detail panel using Tab.
2. Press Left and Right, then with Shift. Try Home and End.
3. Press Enter to reset to the default width. Change the width again and reset by double-clicking the divider.
Expected: Left widens the panel, Right narrows it; Shift makes larger steps. Home sets the minimum, End the maximum allowed width. Enter and double-click restore the default width.
