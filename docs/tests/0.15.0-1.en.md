# 3 · Setup

## E2 · First start
Steps:
1. Start 3MF Katalog Manager Preview.
2. "How should your catalog be organized?" appears – at first in German („Wie soll dein Katalog organisiert sein?“). Click „Später einrichten“ (Set up later) at the bottom.
3. Open the settings (gear icon at the bottom of the left sidebar) → tab „Allgemein“ (General) → „Sprache“ (Language) → choose English.
Expected: The main window is empty (no models yet). The first start is always in German; after step 3 the whole interface is in English and stays English after a restart.

## E3 · Restore the test backup (filament, resin, printers)
Steps:
1. Open Settings → tab "Catalog" → section "Catalog Backup" → "Import catalog".
2. Confirm "This replaces your entire current catalog. Continue?" with "Yes, replace" and choose the file "Testkatalog-Backup.zip" from the test data ZIP.
3. Open "Filament storage" in the left sidebar.
Expected: Under "Filament" 10 spools, including an almost empty one (Sunlu Orange, 120 g) and an empty one (eSun Grau, 0 g). Switch to "Resin" at the top: 4 bottles (one of them empty). In the printer column on the right: Bambu Lab X1C with "AMS 1" (black, white, red in slots 1–3) and a spool holder, Sovol SV08 (purple in the spool holder), Anycubic Kobra S1 with "ACE Pro" (yellow in slot 1). In the resin view: Elegoo Saturn 4 Ultra with a resin vat (Elegoo Grau).

## E4 · Adopt the test catalog (models)
Steps:
1. Settings → "Catalog" → section "Catalog Location" → "Set up" → "Adopt an existing folder structure" → choose the folder "1 Katalog" from the test data ZIP → "Done".
Expected: Message "Imported 15 files in 5 folders.". The catalog shows the folders Deko, Haushalt, Spielzeug, Technik, Werkstatt with 15 models in total (3MF, STL and OBJ), most of them with a preview image.

## E5 · Log file exists
Steps:
1. Settings → tab "Info". Under "Troubleshooting", click "Open folder" next to "Log files".
2. Open the file "{{produkt}}.log" with a text editor.
Expected: The folder is `{{logordner}}`. The file contains lines like `2026-…  INFO  [start] 3MF Katalog Manager 0.15.0-1 (ohne STEP) · … · Schema 39 · … Modelle` and a line with `[import]` for the adoption in E4. Log lines are written in German, also with an English interface.
Note: The .log files in this folder are not anonymized (user name and paths are in them). Please don't send them – part 7 creates a cleaned-up copy for the report.

# 5 · Deliberately broken files

## K1 · Import broken models
Steps:
1. "Import" → "Folder..." → choose the subfolder "Modelle" of "3 Fehlerdateien".
Expected: The app doesn't crash. Only "Leer.stl" is added; the other broken files are skipped and listed in the log file (folder from E5) as `WARN … übersprungen`.
Note: Please write down which message the app itself shows and what happens when you double-click "Leer".

## K2 · Broken archives
Steps:
1. "Import" → "Files..." → select all 4 files from the subfolder "Archive" of "3 Fehlerdateien".
Expected: In the dialog "Extract archives": Verschluesselt.7z → "encrypted – not supported"; Beschaedigt.zip → "damaged or unreadable"; Ohne Modelle.zip → "no models found – will be skipped"; Pfad-Ausbruch.zip → 1 model, after "Extract" the message "1 unsafe entries skipped" appears, and there is no file "Boese.stl" outside the target folder.

## K3 · Wrong images
Steps:
1. In the filament storage, edit a spool (pencil icon) and drag the file "Falsches Format.gif" (subfolder "Bilder" of "3 Fehlerdateien") onto the field "Drop an image here or click".
2. Open a model's detail page → "Upload image" → choose "Zu gross.png".
Expected: (1) "Only PNG, JPG or WebP images are supported." (2) „Bilddatei ist zu gross (> 5242880 Bytes)“ (this message is still German in the English interface) – each without "Report problem", the previous image stays.

## K4 · Broken backups
Steps:
1. Settings → "Catalog" → "Import catalog" → "Yes, replace" → the 3 files from the subfolder "Backups" of "3 Fehlerdateien", one after another.
Expected: A message each time, still in German in the English interface (e.g. „Die Datei ist kein gültiges Katalog-Backup (keine ZIP-Datei)“, „Archiv enthält keine catalog.db“, „Katalog-Datenbank …“), without "Report problem".
Note: Important – afterwards catalog, filament and printers are exactly as before.

## K5 · Invalid names
Steps:
1. Rename a model to `ab/cd`.
Expected: Message „Dateiname darf keine Pfad-Trennzeichen enthalten“ (still German in the English interface), without "Report problem".

## K6 · Printer connection with wrong addresses
Steps:
1. Settings → tab "Printers" → turn on "Printer connection".
2. In the filament storage "Manage printers" → "Sovol SV08" → section "Connection", address `8.8.8.8` → "Test connection".
3. Address `10.254.254.254` → "Test connection" (takes a few seconds).
4. Turn "Printer connection" off again.
Expected: (2) "Only addresses on your home network are allowed." (3) "Not reachable. Is the printer switched on and on the same network? …" – both without "Report problem".

# 6 · A real error

## P1 · Rename a locked file
Only: windows
Steps:
1. Lock the file "Rakete.3mf" the way another program would while it has the file open (adjust the path if "Rakete" was moved during the G tests).
2. In the app, rename "Rakete" to "Rakete 2".
3. Click "Report problem", look at the dialog and close it with "Cancel".
4. Release the file and try renaming again.
Expected: Step 2 – an error message (roughly "The process cannot access the file because it is being used by another process") with "Report problem". Step 3 – the dialog "Report a bug" opens. Step 4 – renaming works.
Note: Lock the file with PowerShell: `$f = [System.IO.File]::Open("<catalog>\Spielzeug\Rakete.3mf", 'Open', 'ReadWrite', 'None'); Read-Host "Rakete.3mf is locked. Press Enter to release"; $f.Close()`

# 7 · "Report a bug" and log file

## F1 · Dialog without a preselection
Steps:
1. Settings → Info → "Report a bug".
Expected: The question "Do you want to send us the log file?", no answer is preselected, the button at the bottom right is greyed out. Esc closes the dialog.

## F2 · Form without a log file
Steps:
1. "Report a bug" → "No, report without log file" → "Open form".
Expected: The browser opens `https://3mfkatalog.de/en/report-a-bug.html?version=0.15.0-1&os=<your system>` (windows/macos/linux). In the form, "App version" ("0.15.0-1 (from the app)") and "Operating system" are already selected. Don't submit the form yet.

## F3 · Log file preview
Steps:
1. "Report a bug" → "Yes, attach the log file". Read through the preview.
Expected: Replaced parts are highlighted: `<user>` instead of your user name, `~` instead of your home folder, `<host>` instead of the computer name, `<katalog>` instead of the catalog folder, IP addresses from K6 as `<ip-1>` and so on.
Note: Please look specifically for your real name, computer name or any other personal detail. If you find one, please note exactly where (without sending the detail itself).

## F4 · Replace file names
Steps:
1. Tick "Replace file names" and untick it again.
Expected: With the tick, file names like "Rakete.3mf" become `<datei-1>.3mf`; without it, the real names are shown.

## F5 · Save and open form
Steps:
1. Tick "Replace file names" → "Save and open form" (click once).
2. Then open the saved file in a text editor.
Expected: Green note "Saved: … – attach it in the form under “Log file”." with the path in your Downloads folder. The browser opens the form, the address additionally ends with `&log=1`; the form now shows the note "Your log file is in your download folder (3mf-katalog-log-….txt). Attach it here." at the field "Log file". The file in the text editor contains exactly the text from the preview. There is exactly one new file `3mf-katalog-log-<date>.txt` in the Downloads folder.
Note: Please attach the saved .txt file in the form at the field "Log file" (not the uncleaned .log files from the folder in E5).

## F6 · Detailed log
Steps:
1. Settings → Info → turn on the switch "Detailed log".
2. Rename a model.
3. "Report a bug" → "Yes, attach the log file".
4. Turn the switch off again afterwards.
Expected: Below the switch it says "On. Turns itself off on <date in 7 days>.". The preview now has lines with `DEBUG` (e.g. for the rename), and "Replace file names" is already ticked.

## F7 · Send a test report
Steps:
1. In the open form (from F5), enter "TEST <your system> – please ignore" under "What happened?".
2. Tick the consent box and submit.
Expected: Confirmation "Thanks! Your report has arrived. …".
