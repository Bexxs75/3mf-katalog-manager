# 6 · A real error

## P1 · Rename a locked file
Only: windows
Steps:
1. In the app, double-click "Rakete" and scroll to the bottom of the detail page. There you see the full path of the file, e.g. `C:\Users\<name>\Downloads\3MF-Testdaten\1 Katalog\Spielzeug\Rakete.3mf`.
2. Open the Start menu, type "PowerShell" and start "Windows PowerShell".
3. Copy the command from the note below, paste it into PowerShell, replace `<path>` with the path from step 1 (keep the quotes) and press Enter. PowerShell shows "Rakete.3mf is locked. Press Enter to release". Keep the window open – as long as it is open, the file is locked as if another program had it open.
4. In the app, rename "Rakete" to "Rakete 2" (right-click → "Rename").
5. Close the rename prompt, click "Rakete" in the list and, on the card "The file cannot be read" in the details panel, click "Report problem". Look at the dialog and close it with "Cancel".
6. Go back to the PowerShell window and press Enter (the file is free again). Then rename again in the app.
Expected: Step 4 – an error message below the input field (roughly "Rename failed: The process cannot access the file because it is being used by another process"), still without "Report problem". Step 5 – the card "The file cannot be read" has "Report problem", the dialog "Report a bug" opens. Step 6 – renaming works.
Note: Command to lock the file: `$f = [System.IO.File]::Open("<path>", 'Open', 'ReadWrite', 'None'); Read-Host "Rakete.3mf is locked. Press Enter to release"; $f.Close()`
