# 5 · Closing the window and settings

## N19001 · Close the window with the X
Steps:
1. Settings → General → Program behaviour: "When the window is closed" is set to "Quit" (default).
2. Close the window with the X (macOS: red dot).
3. Check that the process has ended (Windows: Task Manager; Linux/macOS: note the PID before closing with `ps -ef | grep mf-katalog-manager`, then run `kill -0 <PID>` or `ps -p <PID>` afterwards, which must fail; or Activity Monitor). Do not use `pgrep -x`: the process name has 18 characters and `pgrep` compares only 15.
Expected: The window closes without an error message, the process ends and the catalog is unchanged at the next start.

## N19002 · Close the window with Alt+F4 or Cmd+Q
Steps:
1. Start the app and open a model.
2. Windows and Linux: Alt+F4. macOS: Cmd+Q.
3. Check the process as in N19001.
Expected: The app quits without an error message and without a hanging process.

## N19003 · Minimize to the tray
Steps:
1. Settings → General → Program behaviour: switch "When the window is closed" to minimize to the notification area. Type "Tray" into the settings search.
2. Close the window with the X, choose "Open" from the tray icon (macOS: menu bar), then "Quit" from the icon menu.
Expected: The search for "Tray" finds the option. Closing only hides the window, the app keeps running and "Open" shows the window again; "Quit" really ends the process.
Note: Known limitation: on GNOME (Wayland) the window gets no keyboard focus after "Open" in the icon menu (focus-stealing prevention of the compositor); a click into the window is enough. Just note it in the result.

## N19004 · Settings survive a restart
Steps:
1. Change settings: language to German, switch density or color scheme, one switch under General (for example Program behaviour).
2. Quit the app with the X and start it again.
Expected: All changed settings are still there, including the language.

## N19005 · Window size and maximized state are remembered
Steps:
1. Shrink the window and give it its own size, quit and restart. Then maximize it, quit and restart.
2. On GNOME/Wayland do the same: maximize, quit, restart.
Expected: Size and maximized state come back; on GNOME/Wayland the window starts maximized (it stayed small before). The position is not remembered (known limitation, 0.19.0).

## N19006 · Settings: counter "changed since opening"
Steps:
1. Open Settings and change two values.
2. Read the counter in the header and the marker next to the changed settings. Reset one value.
Expected: The header says "2 changed since opening", the marker reads "Changed since opening" and compares with the value when Settings was opened, not with the default; after the reset it counts 1.

## N19049 · Reverse proxy and trusted proxies
Only: linux
Steps:
1. Start the server with `KATALOG_TRUST_PROXY=1` but without `KATALOG_TRUSTED_PROXIES`.
2. Start with `KATALOG_TRUSTED_PROXIES=<fixed proxy address>/32`, then with a wide range (for example `172.16.0.0/12`).
3. With a proxy in front, sign in wrongly several times from two addresses.
Expected: Without the list the server does not start and names the reason. With `/32` it runs; a range that is too wide produces a warning in the log. The login lock applies per real client; a forged `X-Forwarded-For` from an untrusted sender is ignored.
Note: Operators behind a proxy: give the fixed address (`/32`, IPv6 `/128`) and do not publish port 8080 as well.
