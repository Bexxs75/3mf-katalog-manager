# 6 · A real error

## P1 · Rename a locked file
Only: windows
Steps:
1. In the app, click "Rakete". At the top right, below the name, you see the full path of the file, e.g. `C:\Users\<name>\Downloads\3MF-Testdaten\1 Katalog\Spielzeug\Rakete.3mf`.
2. Open the Start menu, type "PowerShell" and start "Windows PowerShell".
3. Copy the command from the note below, paste it into PowerShell, replace `<path>` with the path from step 1 (keep the quotes) and press Enter. PowerShell shows "Rakete.3mf is locked. Press Enter to release". Keep the window open – as long as it is open, the file is locked as if another program had it open.
4. In the app, rename "Rakete" to "Rakete 2" (right-click → "Rename").
5. In the error message, click "Report problem", look at the dialog and close it with "Cancel".
6. Go back to the PowerShell window and press Enter (the file is free again). Then rename again in the app.
Expected: Step 4 – an error message (roughly "The process cannot access the file because it is being used by another process") with "Report problem". Step 5 – the dialog "Report a bug" opens. Step 6 – renaming works.
Note: Command to lock the file: `$f = [System.IO.File]::Open("<path>", 'Open', 'ReadWrite', 'None'); Read-Host "Rakete.3mf is locked. Press Enter to release"; $f.Close()`

# 8 · New in 0.16.0-1

## V1 · App can only be started once
Steps:
1. Start 3MF Katalog Manager Preview and leave the window open.
2. Start the app a second time (start menu, desktop icon or launcher).
3. Minimize the window of the first app, then start it once more.
Expected: No second window opens. The existing window comes to the front, even when it was minimized. Only one process of the app is running (Task Manager on Windows, Activity Monitor on macOS, `pgrep` on Linux).

## V2 · Details panel only when needed
Steps:
1. Start the app with a catalog and do not click a model yet.
2. Click a model.
3. Close the details panel with the cross at the top right, then select a model and press Esc.
4. Make the window narrower than 1000 pixels and select a model.
Expected: Without a selection there is no details panel on the right and the models use the full width. A click opens it, the cross and Esc close it. In a narrow window it lies over the models. The "Details" button at the top right keeps it open.

## V3 · Status badges in the details panel
Steps:
1. Select a model that is printed and marked as a favourite.
2. Select a model that is not printed and is in the queue.
Expected: Right below the file name there are badges: "Printed" or "Not printed", the material, the filament check ("Filament is enough", "Enough with a spool change", "Filament is not enough" or "Filament unclear"), "Favourite" and "In queue" when they apply.

## V4 · Colors in the 3D preview
Steps:
1. Open "Pflanztopf mit Untersetzer" (Haushalt) by double click and switch to the 3D view.
2. Switch between "File colors" and "Single color" at the top right.
Expected: The pot and the saucer appear in the colors from the file (terracotta and stone grey). A color legend is shown at the bottom left.

## V5 · One variant, switching from the standard version
Steps:
1. First install the last standard version 0.15.3 (without STEP preview) and create a catalog.
2. Install the package of the new version over it (or let the in-app update run).
3. Start the app and open a STEP file.
Expected: The update runs without an error, and the catalog is unchanged. The STEP file shows a 3D preview, and no note about another variant appears.
